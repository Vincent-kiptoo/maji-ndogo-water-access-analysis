# Maji Ndogo Water Access Analysis

## Overview

The **Maji Ndogo Water Access Analysis** project is an end-to-end exploratory data analysis (EDA) that investigates water accessibility across the fictional region of Maji Ndogo. Using SQL and Python, the project uncovers infrastructure challenges, identifies patterns of service failure, evaluates discrepancies between observed data and official reports, and assesses the impact of water accessibility on affected communities.

The objective is to generate data-driven insights that can support evidence-based decision-making for improving water infrastructure and service delivery.

---

## Project Objectives

This project aims to:

- Understand the current state of water access in Maji Ndogo.
- Identify patterns and causes of water infrastructure failures.
- Compare field observations with official reporting.
- Assess the social impact of inadequate water access.
- Generate actionable insights through data analysis and visualization.

---

## Project Structure

| Notebook | Description |
|----------|-------------|
| `01_data_understanding.ipynb` | Initial exploration of the dataset, data quality assessment, and understanding the water infrastructure landscape. |
| `02_infrastructure_failure.ipynb` | Investigation of infrastructure failures, service interruptions, and recurring operational issues. |
| `03_official_discrepancy.ipynb` | Comparison of field observations with official reports to identify inconsistencies and reporting gaps. |
| `04_impact_assessment.ipynb` | Analysis of the effects of water accessibility challenges on communities and overall service delivery. |

---

## Key Questions

The analysis seeks to answer the following questions:

- What does the available data reveal about water access in Maji Ndogo?
- Which water sources experience the highest rates of infrastructure failure?
- Are there discrepancies between official reports and observed field data?
- Which communities are most affected by limited access to clean water?
- What insights can support future improvements in water service delivery?

## Getting Started

### Prerequisites

Before running the notebooks, ensure you have:

- Python 3.x
- Jupyter Notebook or JupyterLab
- MySQL Server
- Required Python libraries

### Installation

1. Clone the repository:

```bash
git clone https://github.com/vincent-kiptoo/maji-ndogo-water-access-analysis.git
```

2. Navigate to the project directory:

```bash
cd maji-ndogo-water-access-analysis
```

3. Launch Jupyter Notebook:

```bash
jupyter notebook
```

4. Open and run the notebooks in the following order:

```
01_data_understanding.ipynb
02_infrastructure_failure.ipynb
03_official_discrepancy.ipynb
04_impact_assessment.ipynb
```
